How To Use It

Normal testing flow for backend and UI work.

1. Pick a device Use the left panel to select an existing virtual device or save a new one.
2. Publish attendance Put one UID per line, then send a batch to test scan ingestion.
3. Test requests Leave auto respond enabled if you want backend MQTT requests to get simulated replies.
